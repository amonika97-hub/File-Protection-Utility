# File Protection Utility

A Python command-line utility for encrypting and decrypting sensitive local files using AES-256 symmetric encryption.

## Features

- AES-256 encryption
- PBKDF2 password-based key derivation
- Random salt generation
- Secure file encryption
- File decryption
- Integrity verification using AES-GCM

## Requirements

- Python 3.x
- cryptography library

Install the library:

```bash
pip install cryptography
